# Interferometría de muy larga base

Técnica que combina señales de radiotelescopios muy separados para lograr una resolución angular equivalente a una apertura efectiva enorme.

## Relaciones
- Es la técnica fundamental del [[Event Horizon Telescope]].
- Permite resolver estructuras a escala de horizonte en [[M87 estrella|M87*]] y [[Sagittarius A estrella|Sagittarius A*]].
