# Ruta — Acreción y observación electromagnética

[[Agujero negro]]
→ atrae materia mediante → [[Acreción]]
→ puede formar → [[Disco de acreción]]
→ que emite radiación
→ permitiendo inferir la presencia del agujero negro.

En algunos sistemas:
[[Acreción]]
→ junto con campos magnéticos y rotación
→ puede alimentar → [[Jet relativista]].
