# Sistema binario

Sistema de dos objetos ligados gravitacionalmente.

## Relaciones
- Un agujero negro con una estrella compañera puede revelar su presencia por [[Acreción]] y dinámica orbital.
- Un binario de agujeros negros puede evolucionar hacia una [[Fusión de agujeros negros]].
- [[Cygnus X-1]] es un ejemplo de sistema binario con agujero negro.
