# Tipos de relación

Las relaciones se expresan con enlaces `[[...]]` dentro de frases legibles.

Ejemplos:

- A **posee** B.
- A **es descrito por** B.
- A **produce** B.
- A **permite observar** B.
- A **aporta evidencia de** B.
- A **depende de** B.
- A **predice** B.
- A **plantea un problema para** B.
- A **es un caso de** B.
- A **fue detectado por** B.
- A **fue propuesto/desarrollado por** B.

Evitar relaciones vagas como "está relacionado con" cuando pueda usarse una relación más informativa.
