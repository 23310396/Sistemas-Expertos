# Knowledge Graph — Agujeros Negros

Base de conocimientos desarrollada en Obsidian sobre el dominio:

**Agujeros negros: formación, física, observación y fenómenos asociados.**

## Estructura

- `00_Admin/` — índice, alcance y organización general.
- `01_Fuentes/` — fuentes utilizadas.
- `02_Conceptos/` — conceptos científicos del dominio.
- `03_Entidades/` — objetos, científicos, observatorios y eventos.
- `04_Relaciones/` — rutas conceptuales que conectan varias notas.
- `.obsidian/` — configuración de la bóveda y de la vista gráfica.

## Cómo abrirlo

1. Descargar o clonar este repositorio.
2. Abrir Obsidian.
3. Seleccionar **Abrir carpeta como bóveda**.
4. Elegir la carpeta raíz del repositorio.
5. Abrir la **Vista gráfica** para explorar las relaciones.

## Herramientas utilizadas

- Obsidian
- OpenCode

Las relaciones entre conceptos se construyen mediante enlaces internos de Obsidian usando el formato `[[Nombre de nota]]`.
